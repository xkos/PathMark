# 收藏夹导入、站点同步与资料库体验修复

依据 2026-09-07 用户跨设备试用反馈实施。保留已有本地数据结构，不修改 `docs/me2ai`。

## 当前行为

- 收藏夹目录按可折叠树显示，补齐没有直接链接的祖先目录；勾选节点选择整个子树，提供全选和取消选择。
- 分类默认未分类，不从收藏夹目录名自动生成。下拉按已有分类、本次新建分组；选择“新建分类”才显示名称输入框和创建按钮，显式创建后可在其他目录复用，确认导入时写入数据库。目录的阅读状态、归档状态和分类仍独立配置。
- 域名映射支持直接选择本次新建站点；共享新站点的名称修改一起更新。导入成功后转为已有站点映射，避免再次操作时重复创建。
- 保存站点与同步资料分开：保存不要求预演；已保存站点的同步按钮列出匹配该站点的未入站条目，按 host / endpoint / 条目分组，可全选或选子树。
- 同步在 IndexedDB 单个事务内完成。同一站点、同一规范化 resourceKey 只保留一条。查询参数仍遵循站点身份策略，不把不同身份参数的资源误合并。
- 已入站的目标条目优先保留 ID、标题、来源地址和分类；若分类为空则采用传入条目的分类。不同的非空笔记拼接、标签去重、阅读状态取 read > reading > unread、保留最早首次已读时间和最晚打开时间，打开次数相加。双方均归档才保留归档状态。
- 两个不同的非空分类无法同时保存在当前单分类模型中，保留目标条目分类。没有修改数据模型为多分类。
- 重复同步不再生成条目；未选择条目、不匹配该站点的条目和已经属于站点的条目不被同步迁移。
- 资料库每页渲染 100 条；全选作用于全部筛选结果，可跨页批量删除。返回条目页时重新读取数据库。
- 初始资料库及“全部条目”入口默认选择未入站，可从站点筛选切换到全部站点。移除收藏/已读日期筛选、独立标签筛选以及不再适用的默认视图设置控件；保留历史导入导出字段兼容。
- 标签仍是独立于收藏分类的现有元数据，可在条目编辑中管理，也可通过统一搜索命中。
- 原始地址仅为来源 URL，并不代表保存网页内容。保留底层字段用于识别、导入导出和回退；入站条目的打开菜单不再提供“原始地址”，展示和打开采用当前站点解析地址。

## 验证

- `cd chromium && npm test`：70 个测试通过，覆盖同步合并、保留已有条目及阅读记录、非目标条目不变、重复同步和批量删除。
- `cd chromium && npm run build`：TypeScript、页面/后台构建及扩展包校验通过。仍存在既有大型共享脚本的构建体积提示。
- `chromium/scripts/smoke-library.cjs`：在本地开发服务器上使用独立无头 Chromium 会话和合成数据。需要可用的 Playwright；可设置 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_EXECUTABLE_PATH` 指向本机安装。
- 浏览器覆盖 7000 条资料、每页 100 条、全选 7000 条、直接保存新增 endpoint、同步合并、授权读取模拟目录树、子树级选择、已有/新建分类和新建站点复用。
- 本机合成数据刷新至首批行出现约 150–180 ms；这是开发服务器与本机无头浏览器测试，不是用户另一台设备的实测，也不是数据库查询只加载 100 条。当前仍一次读取条目数据，主要消除全量 DOM 渲染成本。
- 浏览器收藏夹权限与目录接口在测试中使用模拟返回，没有访问或修改真实浏览器收藏夹。

## 0.2.5 界面语言

- 首次默认英语，不再自动跟随浏览器语言。在设置与数据中提供 Language / 界面语言选择，使用已有完整语言目录。
- 语言偏好保存在扩展同源 localStorage，与条目数据分开。切换立即生效，通过 storage 事件同步已打开的资料库和弹窗；更新文档标题、语言和文字方向。
- 72 个测试及构建通过。`chromium/scripts/smoke-language.cjs` 验证中文浏览器下首次默认英语、即时切换、弹窗同步、刷新后持久化及切回英语。

## 0.2.7 导入域名排除

- 域名行提供“本次不导入”；按精确 hostname 排除所有目录中该域名的地址，覆盖 HTTP/HTTPS 和不同端口，不连带其他子域名。
- 被排除域名在折叠列表中可恢复。修改排除选择立即失效旧预览，重新读取收藏夹或文件时重置排除选择。
- 排除规则同时作用于预览和事务写入；不为仅含排除地址的目录/域名创建分类或站点，不修改已保存条目。全部排除时不能导入。
- 74 个测试及构建通过，覆盖预览/写入一致性、已有数据保留、恢复和全部排除。

## 0.2.9 导入状态合并

- 导入界面移除单独的归档列和勾选框，阅读状态下拉统一提供未读、在读、已读、归档。
- 选择归档只设置归档标记并保留该目录规则的阅读状态；改选其他状态时取消归档。存储模型保持兼容。
- 浏览器验证四个选项的切换、无独立归档框，以及实际导入后归档标记和已读状态同时保留。构建通过。

## 0.2.13 分页与全选

- 参考 Carbon 数据表分页结构（https://carbondesignsystem.com/components/pagination/usage/），把每页条数与条目范围放在一组，把上一页、可点击页码、下一页放在相邻导航组；当前页高亮，首尾边界禁用，长页码省略中间部分。
- 全选筛选结果改为复选框，作用于全部匹配条目而非当前页；取消勾选清空全部选择，部分选中显示半选。悬停和键盘聚焦显示筛选总数与已选数量。
- 本机浏览器使用7000条合成数据验证全选、取消、半选、跳到末页/首页、边界禁用，并保留实际导入及批量删除回归。构建通过。
