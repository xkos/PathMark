# 项目文档目录约定

`docs` 按“用户提供给 AI 的稳定事实”和“AI 在执行过程中产生的工作材料”分区。

```text
docs/
├── README.md
├── ai2ai/
│   ├── plans/
│   ├── tasks/
│   ├── decision.md
│   └── status.md
└── me2ai/
    ├── README.md
    ├── prds/
    ├── models/
    ├── schemas/
    └── examples/
```

## `ai2ai`

存放 AI 可创建、更新和整理的执行材料：

- `plans/`：阶段计划、实施方案和验证计划；
- `tasks/`：任务拆分、验收清单和执行记录；
- `decision.md`：AI 工作过程中形成的技术或实施决策；
- `status.md`：项目唯一的当前状态快照。

`status.md` 只描述当前事实，不追加历史日志。状态变化时直接重写已经失效的内容。历史应由 Git 提供，不能堆积在 `status.md` 中。

## `me2ai`

存放用户确认后提供给 AI 的产品事实和约束，包括 PRD、抽象模型、数据模型及其机器可读定义。

`docs/me2ai/**` 是保护区。AI 可以读取，但严禁自行新增、修改、移动、重命名或删除其中任何内容。每次变更前都必须说明目标文件和变更目的，并取得用户明确同意。

本目录约定本身如需改变，也必须先取得用户同意。
