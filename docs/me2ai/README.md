# me2ai 保护区

本目录保存用户确认的产品事实、需求和模型，是 AI 执行工作的输入基线。

## 修改规则

AI 可以读取本目录，但不得自动执行以下操作：

- 新增或修改文件内容；
- 移动或重命名文件；
- 删除文件或目录；
- 通过格式化、生成器或迁移脚本间接改写文件。

需要变更时，AI 必须先向用户说明：

1. 拟修改的文件；
2. 修改原因和具体范围；
3. 对需求、模型或兼容性的影响。

只有取得用户明确同意后，才能执行该次变更。一次同意不自动授权后续变更。

本目录当前包含：

- `prds/`：产品需求文档；
- `models/`：项目术语、抽象模型、领域对象、存储和 URL 身份算法；
- `schemas/`：导入导出的机器可读约束；
- `examples/`：符合 Schema 的示例数据。
