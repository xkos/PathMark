# 本地阅读收藏夹——抽象模型

本上下文描述浏览器中待阅读资料的收集、识别与阅读历史。它把可能变化的访问地址与用户认为是同一份资料的身份分开。

## Language

**站点（Site）**:
用户认知中的同一个内容来源；一个站点可以拥有多个历史或当前可用的 Endpoint。
_Avoid_: 域名、网站地址

**Endpoint**:
属于某个站点的 URL 前缀，由协议、主机、可选端口和可选路径前缀组成。Endpoint 是访问入口，不是资料身份。
_Avoid_: 域名、镜像、Base URL

**收藏条目（Item）**:
用户保存的一份待阅读或已阅读资料，包含标题、说明、标签和阅读状态。
_Avoid_: 浏览器书签、URL 记录

**收藏分类（Collection）**:
用户主动建立的资料归类，可嵌套；它表达“我把资料放在哪里”，与表达内容来源的站点相互独立。
_Avoid_: 站点、标签

**资源键（Resource Key）**:
收藏条目在所属站点内部的稳定标识，由相对路径和被保留的身份查询参数构成。
_Avoid_: 完整 URL、原始地址

**规范键（Canonical Key）**:
由站点身份和资源键组成、用于识别重复收藏或当前页面是否已记录的全局稳定标识。
_Avoid_: URL 哈希

**原始地址（Original URL）**:
收藏条目首次保存时的完整地址，仅用于追溯，不承担身份判断。
_Avoid_: 规范地址

**解析地址（Resolved URL）**:
使用站点当前 Endpoint 与资源键组合得到的候选访问地址。
_Avoid_: 原始地址、永久链接

**阅读状态（Reading State）**:
收藏条目当前的阅读任务进度，只能是未读、阅读中或已读；它不抹除资料曾经读过的历史事实。
_Avoid_: 归档状态

**曾读记录（Read History）**:
收藏条目是否曾经被标记为已读的永久事实，以首次已读时间记录；之后重新标为未读也不会清除。
_Avoid_: 当前阅读状态、最近打开时间

**归档状态（Archive State）**:
收藏条目是否从默认工作列表中隐藏，与阅读状态相互独立。
_Avoid_: 已读

**未归站条目（Unassigned Item）**:
尚未关联站点、只能按规范化完整 URL 判断身份的收藏条目。
_Avoid_: 无效条目
