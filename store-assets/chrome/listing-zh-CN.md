# PathMark Chrome 应用商店文案（简体中文）

## 产品信息

名称：

```text
PathMark - 本地阅读资料库
```

摘要：

```text
用阅读状态、分类、笔记和稳定的站点身份，在浏览器本地整理网页资料。
```

详细描述：

```text
PathMark 帮助你在收藏网页时保留下次回来真正需要的上下文：明确的阅读状态、个人说明、标签和分类。

不同于传统收藏夹，PathMark 将稳定的“站点”与具体域名和 URL 前缀分开。一个站点可以包含多个 Endpoint；当资料来源更换域名或移动路径时，同一份内容仍能保留原有的阅读身份。

主要功能：
• 将当前页面保存为未读、阅读中或已读。
• 通过工具栏图标直接查看当前页面状态。
• 添加说明、标签和多层分类。
• 将新旧域名归入同一个站点。
• 搜索、筛选、编辑、迁移、归档和删除资料。
• 经你授权后直接读取当前浏览器收藏夹，或导入收藏夹 HTML，并在写入前映射目录状态与站点。
• 通过 JSON 导入或导出完整资料库。

PathMark 坚持本地优先：没有账号、云同步、广告、分析或遥测。阅读资料只保存在浏览器配置文件的 IndexedDB 中，不会发送给开发者或第三方。
```


## 权限与数据披露

`bookmarks` 可选权限理由：

```text
仅当用户主动点击“授权并读取”时，PathMark 才请求 bookmarks 可选权限，并读取当前浏览器收藏夹的目录、标题、URL 与收藏时间，用于生成可编辑的本地导入预览。PathMark 不调用创建、修改或删除收藏夹的接口，不会改变原收藏夹；读取的数据不会发送给开发者或第三方。拒绝该权限不影响 HTML 导入及其他核心功能。
```

需要披露的数据：

- 网站活动：用户明确选择导入的收藏夹 URL、域名、标题及目录结构。
- 用户生成内容：用户输入的说明、标签、分类、阅读状态、Site 和 Endpoint 规则。
