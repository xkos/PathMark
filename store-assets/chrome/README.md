# Chrome Web Store submission assets

Prepared for PathMark `0.1.1`.

## Files

- `pathmark-small-promo-440x280.png`: required global small promotional tile; intentionally contains no text so it works across locales.
- `pathmark-sites-1280x800.png`: global English screenshot showing one Site with multiple Endpoint prefixes.
- `pathmark-library-zh-CN-1280x800.png`: Simplified Chinese localized library screenshot.
- `listing-en.md`: English listing copy and dashboard declarations.
- `listing-zh-CN.md`: Simplified Chinese localized listing copy.

Upload the ZIP from the `v0.1.1` GitHub Release as the extension package. Do not upload the CRX to Chrome Web Store.

Privacy policy URLs:

- `https://pathmark.elenchlab.app/en/privacy/`
- `https://pathmark.elenchlab.app/zh-CN/privacy/`

The promotional image background was created with the built-in ImageGen tool and cropped to the exact store dimensions. Both screenshots were captured from the real locally running PathMark application with real IndexedDB data; they are not reconstructed mockups.
