Für Menschen, die tatsächlich zum Lesen zurückkehren

Von der schnellen Erfassung bis zum Wiederfinden bewahrt PathMark mehr als einen Link: den Kontext, den Ihr zukünftiges Ich braucht.

01

Inhalte über Domains hinweg erkennen

Eine Website kann mehrere Domains oder URL-Präfixe enthalten. Nach einem Umzug können passende Pfade eine stabile Inhaltsidentität behalten.

02

Klare Lesestatus

Ungelesen, wird gelesen, gelesen und archiviert bleiben getrennt. Das Symbol in der Symbolleiste ändert seine Farbe passend zur aktuellen Seite.

03

Den Grund speichern, nicht nur die URL

Speichern Sie Titel, persönliche Notiz, Tags und Sammlung, damit Sie sich erinnern, warum etwas wichtig war und worauf Sie achten wollten.

04

Bestehende Websites automatisch zuordnen

Das Pop-up erkennt die aktuelle Domain, wählt eine bekannte Website aus oder hilft beim Erstellen einer neuen Website mit ihrem ersten Endpoint.

05

Eine vollständige lokale Bibliothek

Suchen und filtern Sie nach Status, Website, Sammlung, Tag oder Datum. Organisieren Sie gesammelt, migrieren Sie Identitäten und wählen Sie, wo ein Element geöffnet wird.

06

Ihre Daten bleiben Ihre Daten

Bibliotheksdaten bleiben lokal im Browser. Exportieren Sie vollständige JSON-Sicherungen und führen Sie sie transaktional zusammen oder stellen Sie sie wieder her.

In drei Schritten ein Lesegedächtnis aufbauen

Das Erfassen bleibt unkompliziert. Die detaillierte Organisation kann warten, bis Sie sie wirklich brauchen.

PathMark auf einer beliebigen Seite öffnen

Über das Symbol oder die Tastenkombination sehen Sie sofort, ob die Seite gespeichert ist und welchen Lesestatus sie hat.

Kontext ergänzen und speichern

Notieren Sie eine Notiz, Tags und eine Sammlung. Website und Endpoint werden automatisch aus der aktuellen URL vorgeschlagen.

Lesen, migrieren und wiederentdecken

Auch nach einem Domainwechsel hilft die stabile Website-Identität, dieselbe Ressource erneut zu erkennen und zu öffnen.

Beginnen Sie mit der nächsten Seite, die Sie später lesen möchten.

Installieren Sie PathMark aus dem Chrome Web Store und organisieren Sie, was Sie lesen möchten, gerade lesen und bereits abgeschlossen haben. Entwickler finden Quellcode und eigenständige Builds auch auf GitHub.
