隐私政策

PathMark 的设计目标是让阅读资料库始终由你掌控。扩展数据仅在浏览器本地处理和保存，不会发送给 PathMark 开发者或任何第三方。

生效日期：2026 年 8 月 12 日 · 适用于 PathMark 浏览器扩展和官方网站。

1. PathMark 处理的数据

使用扩展时，PathMark 可能处理当前标签页的 URL 和标题、收藏或打开条目的时间，以及你主动输入的说明、标签、分类、阅读状态、站点和 Endpoint 规则。PathMark 不读取页面正文、密码、表单内容、Cookie 或完整浏览历史。

2. 数据用途

上述信息仅用于提供 PathMark 面向用户的阅读资料库功能：识别当前页面是否已收藏、建议站点、在网站更换域名后维持稳定的资料身份、组织收藏，以及根据阅读状态更新工具栏图标。

3. 本地存储与保留期限

扩展数据保存在浏览器配置文件内的 IndexedDB 中。PathMark 没有账号系统或云同步服务。数据会保留在你的设备上，直到你删除条目、清空资料库、移除扩展或浏览器配置文件，或者通过导入替换数据。你可以随时导出完整 JSON 备份。

4. 传输与共享

扩展不会把收藏 URL、标题、说明、标签、分类、阅读状态或站点配置发送给开发者、分析服务、广告商或其他第三方。扩展不包含广告、跟踪 SDK、遥测或远程代码。公开网站为静态页面，不接收扩展数据。

5. 出售与禁止用途

PathMark 不出售用户数据，不将数据用于广告、信用评估、借贷或与扩展单一用途无关的目的。对从 Chrome API 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

6. 你的控制权

  • 编辑或删除单个收藏条目。
  • 将完整资料库导出为 JSON。
  • 在 PathMark 设置中清空全部本地业务数据。
  • 移除扩展以停止未来的数据处理。

7. 权限说明

PathMark 使用 tabs 权限，在识别收藏页面及让工具栏图标与活动页面状态保持同步时读取标签页 URL 和标题。这些信息只在本地计算，不用于读取页面正文，也不会发送到其他位置。

8. 政策变更与联系

如果 PathMark 的数据处理方式发生实质变化，我们会在发布新行为之前更新本政策和扩展内的披露。隐私问题和相关请求可以通过项目的 GitHub Issue 提交。
