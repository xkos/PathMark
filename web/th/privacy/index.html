นโยบายความเป็นส่วนตัว

PathMark ออกแบบมาเพื่อให้คุณควบคุมคลังบทอ่านได้เอง ข้อมูลส่วนขยายจะถูกประมวลผลและจัดเก็บในเบราว์เซอร์ของคุณ และไม่ถูกส่งให้นักพัฒนา PathMark หรือบุคคลที่สาม

มีผลตั้งแต่: 15 สิงหาคม 2026 · ใช้กับส่วนขยายเบราว์เซอร์และเว็บไซต์ PathMark

0.2.14 · 2026-10-10

การทำเครื่องหมายลิงก์ที่บันทึกเป็นตัวเลือกและปิดไว้ตามค่าเริ่มต้น เมื่อเปิดจะขอเข้าถึงเว็บไซต์ HTTP/HTTPS สิทธิ์ scripting อ่านที่อยู่และตำแหน่งลิงก์เพื่อแสดงเครื่องหมายสีหมวดหมู่ โดยจับคู่ในเครื่องและไม่ส่งที่อยู่ออกไป สิทธิ์ storage บันทึกตัวเลือกไว้ในเครื่องเพื่อกู้คืนหลังเริ่มใหม่หรืออัปเดต เมื่อปิดจะลบเครื่องหมายและสิทธิ์เข้าถึงเว็บไซต์ สีไอคอนจะแสดงหมวดหมู่แทนสถานะการอ่าน

1. ข้อมูลที่ PathMark ประมวลผล

เมื่อใช้ส่วนขยาย PathMark อาจประมวลผล URL และชื่อแท็บปัจจุบัน เวลาที่บันทึกหรือเปิดรายการ และข้อมูลที่คุณป้อน เช่น บันทึกย่อ แท็ก คอลเลกชัน สถานะการอ่าน เว็บไซต์ และกฎ endpoint เมื่อคุณเลือกนำเข้าโดยตรงจากเบราว์เซอร์อย่างชัดเจน PathMark ยังอ่านโฟลเดอร์บุ๊กมาร์ก ชื่อ URL และเวลาบันทึกในเครื่อง PathMark ไม่อ่านเนื้อหาหน้า รหัสผ่าน ข้อมูลแบบฟอร์ม คุกกี้ หรือประวัติการท่องเว็บทั้งหมด

2. วัตถุประสงค์การใช้ข้อมูล

ข้อมูลใช้เฉพาะสำหรับคุณสมบัติคลังบทอ่านของ PathMark ได้แก่ ตรวจว่าบันทึกหน้าปัจจุบันหรือยัง เสนอเว็บไซต์ เก็บข้อมูลระบุทรัพยากรที่เสถียรเมื่อโดเมนเปลี่ยน จัดระเบียบรายการ สร้างตัวอย่างนำเข้าบุ๊กมาร์กที่แก้ไขได้ และปรับไอคอนแถบเครื่องมือตามสถานะการอ่าน

3. การจัดเก็บในเครื่องและระยะเวลา

ข้อมูลส่วนขยายเก็บใน IndexedDB ภายในโปรไฟล์เบราว์เซอร์ PathMark ไม่มีระบบบัญชีหรือการซิงค์คลาวด์ ข้อมูลจะอยู่ในอุปกรณ์จนกว่าคุณจะลบรายการ ล้างคลัง ลบส่วนขยายหรือโปรไฟล์เบราว์เซอร์ หรือแทนที่ข้อมูลด้วยการนำเข้า คุณส่งออกข้อมูลสำรอง JSON ได้ทุกเมื่อ

4. การส่งและเปิดเผยข้อมูล

ส่วนขยายไม่ส่ง URL ชื่อ บันทึกย่อ แท็ก คอลเลกชัน สถานะการอ่าน หรือการกำหนดค่าเว็บไซต์ที่บันทึกไว้ให้นักพัฒนา ผู้ให้บริการวิเคราะห์ ผู้ลงโฆษณา หรือบุคคลที่สาม ไม่มีโฆษณา SDK ติดตาม การวัดและส่งข้อมูล หรือโค้ดจากระยะไกล เว็บไซต์สาธารณะเป็นแบบคงที่และไม่รับข้อมูลส่วนขยาย

5. การขายและการใช้งานต้องห้าม

PathMark ไม่ขายข้อมูลผู้ใช้ และไม่ใช้เพื่อโฆษณา ประเมินเครดิต ให้สินเชื่อ หรือวัตถุประสงค์ที่ไม่เกี่ยวข้องกับหน้าที่เดียวของส่วนขยาย การใช้ข้อมูลจาก Chrome API ทั้งหมดเป็นไปตามนโยบายข้อมูลผู้ใช้ของ Chrome Web Store รวมถึงข้อกำหนดการใช้งานแบบจำกัด

6. การควบคุมของคุณ

  • แก้ไขหรือลบรายการที่บันทึกแต่ละรายการ
  • ส่งออกคลังทั้งหมดเป็น JSON
  • ปฏิเสธหรือเพิกถอนสิทธิ์บุ๊กมาร์กที่ไม่บังคับในการตั้งค่าส่วนขยายของเบราว์เซอร์ และยังใช้การนำเข้า HTML ได้
  • ล้างข้อมูลในเครื่องทั้งหมดในการตั้งค่า PathMark
  • ถอนการติดตั้งส่วนขยายเพื่อหยุดการประมวลผลต่อไป

7. สิทธิ์

PathMark ใช้สิทธิ์ tabs เพื่ออ่าน URL และชื่อแท็บเมื่อจำเป็น เพื่อจดจำหน้าที่บันทึกและปรับไอคอนแถบเครื่องมือให้ตรงกับหน้าที่ใช้งาน ข้อมูลจะถูกประเมินในเครื่อง ไม่ใช้เพื่ออ่านเนื้อหาหน้า และไม่ถูกส่งไปที่ใด

PathMark ประกาศ bookmarks เป็นสิทธิ์ที่ไม่บังคับ และจะขอหลังคุณเลือก “อนุญาตและอ่าน” เท่านั้น แม้คำเตือนของเบราว์เซอร์อาจระบุว่า “อ่านและเปลี่ยนบุ๊กมาร์ก” แต่ PathMark เรียกเฉพาะ API ที่อ่านโครงสร้างบุ๊กมาร์ก ส่วนขยายไม่สร้าง อัปเดต ย้าย หรือลบบุ๊กมาร์กต้นฉบับ การปฏิเสธไม่กระทบการนำเข้า HTML หรือคุณสมบัติหลักอื่น

8. การเปลี่ยนแปลงและการติดต่อ

หากแนวทางข้อมูลของ PathMark เปลี่ยนแปลงอย่างมีนัยสำคัญ นโยบายและข้อมูลส่วนขยายนี้จะถูกอัปเดตก่อนเผยแพร่พฤติกรรมใหม่ ส่งคำถามหรือคำขอด้านความเป็นส่วนตัวได้ทาง ระบบติดตามปัญหา GitHub ของโครงการ
