개인정보 처리방침

PathMark는 사용자가 자신의 읽기 라이브러리를 직접 통제할 수 있도록 설계되었습니다. 확장 프로그램 데이터는 브라우저 안에서 처리되고 저장되며 PathMark 개발자나 제3자에게 전송되지 않습니다.

시행일: 2026년 8월 15일 · PathMark 브라우저 확장 프로그램과 웹사이트에 적용됩니다.

1. PathMark가 처리하는 데이터

확장 프로그램을 사용할 때 PathMark는 현재 브라우저 탭의 URL과 제목, 항목을 저장하거나 연 시간, 사용자가 입력한 메모, 태그, 컬렉션, 읽기 상태, 사이트, 엔드포인트 규칙을 처리할 수 있습니다. 브라우저에서 직접 가져오기를 명시적으로 선택한 경우 북마크 폴더, 제목, URL, 저장 시간도 로컬에서 읽습니다. 페이지 본문, 비밀번호, 양식 입력, 쿠키 또는 전체 브라우저 기록은 읽지 않습니다.

2. 데이터 이용 목적

이 정보는 현재 페이지의 저장 여부 확인, 사이트 제안, 도메인 변경 시에도 안정적인 리소스 식별 정보 유지, 항목 정리, 편집 가능한 북마크 가져오기 미리보기 생성, 읽기 상태를 반영하는 도구 모음 아이콘 업데이트 등 PathMark의 사용자용 읽기 라이브러리 기능을 제공하는 데만 사용됩니다.

3. 로컬 저장 및 보관

확장 프로그램 데이터는 브라우저 프로필 내부의 IndexedDB에 저장됩니다. PathMark에는 계정 시스템이나 클라우드 동기화 서비스가 없습니다. 항목 삭제, 라이브러리 비우기, 확장 프로그램이나 브라우저 프로필 제거, 가져오기를 통한 데이터 교체 전까지 데이터는 기기에 남습니다. 언제든 JSON 백업을 내보낼 수 있습니다.

4. 전송 및 공유

확장 프로그램은 저장한 URL, 제목, 메모, 태그, 컬렉션, 읽기 상태 또는 사이트 구성을 개발자, 분석 제공업체, 광고주나 기타 제3자에게 전송하지 않습니다. 광고, 추적 SDK, 원격 측정 또는 원격 코드를 포함하지 않습니다. 공개 웹사이트는 정적 사이트이며 확장 프로그램 데이터를 받지 않습니다.

5. 판매 및 금지된 용도

PathMark는 사용자 데이터를 판매하지 않으며 광고, 신용도 평가, 대출 또는 확장 프로그램의 단일 목적과 무관한 용도로 사용하지 않습니다. Chrome API에서 받은 정보의 모든 사용은 제한적 사용 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다.

6. 사용자가 이용할 수 있는 제어 기능

  • 저장된 항목을 개별적으로 편집하거나 삭제합니다.
  • 전체 라이브러리를 JSON으로 내보냅니다.
  • HTML 가져오기를 계속 사용하면서 브라우저 확장 프로그램 설정에서 선택적 북마크 권한을 거부하거나 철회합니다.
  • PathMark 설정에서 모든 로컬 데이터를 지웁니다.
  • 확장 프로그램을 제거해 이후의 모든 처리를 중단합니다.

7. 권한

PathMark는 저장된 페이지를 식별하고 활성 페이지와 도구 모음 아이콘을 동기화하는 데 필요할 때 tabs 권한으로 탭의 URL과 제목을 읽습니다. 이 정보는 로컬에서 평가되며 페이지 본문을 읽거나 외부로 전송하는 데 사용되지 않습니다.

PathMark는 bookmarks를 선택적 권한으로 선언하고 사용자가 “승인하고 읽기”를 클릭한 후에만 요청합니다. 브라우저 경고에는 “북마크 읽기 및 변경”이라고 표시될 수 있지만 PathMark는 북마크 트리를 읽는 API만 호출합니다. 원래 북마크를 만들거나 업데이트하거나 이동하거나 삭제하지 않습니다. 권한을 거부해도 HTML 가져오기나 다른 핵심 기능에는 영향이 없습니다.

8. 변경 및 문의

PathMark의 데이터 처리 방식이 실질적으로 변경되면 새로운 동작을 출시하기 전에 이 방침과 확장 프로그램의 고지 내용을 업데이트합니다. 질문이나 개인정보 보호 요청은 프로젝트의 GitHub 이슈 트래커에서 제출할 수 있습니다.
