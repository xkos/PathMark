실제로 다시 읽으러 오는 사람을 위해

빠른 저장부터 재발견까지, PathMark는 링크뿐 아니라 미래의 나에게 필요한 맥락도 보존합니다.

01

도메인이 달라도 같은 콘텐츠 인식

하나의 사이트에 여러 도메인이나 URL 접두사를 등록할 수 있습니다. 사이트가 이전해도 일치하는 경로는 안정적인 콘텐츠 식별 정보를 유지합니다.

02

명확하게 구분되는 읽기 상태

읽지 않음, 읽는 중, 읽음, 보관됨을 구분합니다. 도구 모음 아이콘 색상도 현재 페이지의 상태에 따라 바뀝니다.

03

URL뿐 아니라 저장한 이유까지

제목, 개인 메모, 태그, 컬렉션을 기록해 왜 중요했는지, 나중에 무엇을 살펴봐야 하는지 기억할 수 있습니다.

04

기존 사이트 자동 일치

팝업이 현재 도메인을 인식해 등록된 사이트를 선택합니다. 없다면 새 사이트와 첫 엔드포인트 생성을 도와줍니다.

05

완전한 로컬 라이브러리

상태, 사이트, 컬렉션, 태그, 날짜로 검색하고 필터링합니다. 일괄 정리, 식별 정보 이전, 항목을 열 주소 선택도 지원합니다.

06

내 데이터는 내가 소유

라이브러리 데이터는 브라우저 안에 보관됩니다. 전체 JSON 백업을 내보내고 트랜잭션 단위로 병합하거나 복원할 수 있습니다.

세 단계로 읽기의 기억 만들기

저장은 가볍게, 자세한 정리는 실제로 필요할 때 할 수 있습니다.

어느 페이지에서든 PathMark 열기

도구 모음 아이콘이나 단축키를 사용해 페이지 저장 여부와 현재 읽기 상태를 바로 확인합니다.

맥락을 더해 저장하기

메모, 태그, 컬렉션을 기록합니다. 현재 URL에서 사이트와 엔드포인트가 자동으로 제안됩니다.

읽고, 이전하고, 다시 발견하기

도메인이 바뀐 뒤에도 안정적인 사이트 식별 정보가 같은 리소스를 다시 인식하고 여는 데 도움을 줍니다.
