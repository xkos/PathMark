Política de privacidad

PathMark está diseñado para que mantengas el control de tu biblioteca de lectura. Los datos de la extensión se procesan y almacenan localmente en el navegador y no se envían al desarrollador de PathMark ni a terceros.

Fecha de entrada en vigor: 15 de agosto de 2026 · Aplicable a la extensión de navegador y al sitio web de PathMark.

0.2.14 · 2026-10-10

El marcado opcional de enlaces guardados está desactivado por defecto. Al activarlo se solicita acceso a sitios HTTP/HTTPS. scripting consulta direcciones y posiciones de enlaces para marcarlos con el color de su colección; la comparación es local y no transmite direcciones. storage guarda la opción localmente para restaurarla tras reinicios o actualizaciones. Desactivar elimina las marcas y el acceso a sitios. El color del icono indica ahora la colección, no el estado de lectura.

1. Datos que gestiona PathMark

Al usar la extensión, PathMark puede gestionar la URL y el título de la pestaña actual, la hora en que guardas o abres un elemento y la información que introduces, como notas, etiquetas, colecciones, estado de lectura, sitios y reglas de endpoints. Cuando eliges expresamente importar directamente desde el navegador, PathMark también lee localmente las carpetas, títulos, URL y fechas guardadas de los marcadores. PathMark no lee el contenido de las páginas, contraseñas, datos de formularios, cookies ni el historial completo del navegador.

2. Para qué se utilizan estos datos

La información se utiliza únicamente para ofrecer las funciones visibles de la biblioteca de lectura de PathMark: reconocer si la página actual está guardada, sugerir un sitio, mantener una identidad de recurso estable cuando cambian los dominios, organizar elementos, crear una vista previa editable de la importación de marcadores y actualizar el icono de la barra de herramientas según el estado de lectura.

3. Almacenamiento local y conservación

Los datos de la extensión se guardan en IndexedDB dentro del perfil del navegador. PathMark no tiene sistema de cuentas ni servicio de sincronización en la nube. Los datos permanecen en el dispositivo hasta que eliminas un elemento, borras la biblioteca, quitas la extensión o el perfil del navegador, o reemplazas los datos mediante una importación. Puedes exportar una copia JSON en cualquier momento.

4. Transmisión y uso compartido

La extensión no transmite tus URL, títulos, notas, etiquetas, colecciones, estados de lectura ni configuraciones de sitios al desarrollador, proveedores de análisis, anunciantes u otros terceros. No contiene publicidad, SDK de seguimiento, telemetría ni código remoto. El sitio web público es estático y no recibe datos de la extensión.

5. Venta y usos prohibidos

PathMark no vende datos de usuarios ni los utiliza para publicidad, evaluación crediticia, préstamos o fines ajenos al propósito único de la extensión. Todo uso de información recibida de las API de Chrome cumple la Política de datos de usuario de Chrome Web Store, incluidos sus requisitos de Uso limitado.

6. Tus controles

  • Editar o eliminar individualmente los elementos guardados.
  • Exportar toda la biblioteca como JSON.
  • Denegar o revocar el permiso opcional de marcadores en la configuración de extensiones del navegador sin dejar de usar la importación de HTML.
  • Borrar todos los datos locales desde la configuración de PathMark.
  • Quitar la extensión para detener cualquier procesamiento futuro.

7. Permisos

PathMark utiliza el permiso tabs para leer la URL y el título de una pestaña cuando es necesario para reconocer páginas guardadas y mantener el icono de la barra de herramientas sincronizado con la página activa. La información se evalúa localmente, no se usa para leer el contenido de la página ni se envía al exterior.

PathMark declara bookmarks como permiso opcional y solo lo solicita después de que pulses «Autorizar y leer». Aunque el aviso del navegador puede indicar «leer y cambiar marcadores», PathMark solo llama a la API que lee el árbol de marcadores; no crea, actualiza, mueve ni elimina los marcadores originales. Denegar el permiso no afecta a la importación de HTML ni a otras funciones principales.

8. Cambios y contacto

Si las prácticas de datos de PathMark cambian sustancialmente, esta política y la información de la extensión se actualizarán antes de publicar el nuevo comportamiento. Puedes enviar preguntas y solicitudes de privacidad mediante el sistema de incidencias de GitHub del proyecto.
