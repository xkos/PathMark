Kebijakan Privasi

PathMark dirancang agar kendali atas pustaka bacaan tetap berada di tangan Anda. Data ekstensi diproses dan disimpan secara lokal di peramban, serta tidak dikirim kepada pengembang PathMark atau pihak ketiga.

Berlaku sejak: 15 Agustus 2026 · Berlaku untuk ekstensi peramban dan situs web PathMark.

1. Data yang diproses PathMark

Saat Anda menggunakan ekstensi, PathMark dapat memproses URL dan judul tab saat ini, waktu item disimpan atau dibuka, serta informasi yang Anda masukkan seperti catatan, tag, koleksi, status baca, situs, dan aturan endpoint. Saat Anda secara jelas memilih impor langsung dari peramban, PathMark juga membaca folder markah, judul, URL, dan waktu penyimpanan secara lokal. PathMark tidak membaca isi halaman, kata sandi, data formulir, kuki, atau seluruh riwayat penjelajahan.

2. Tujuan penggunaan data

Informasi hanya digunakan untuk fitur pustaka bacaan PathMark yang ditujukan bagi pengguna: menentukan apakah halaman saat ini sudah disimpan, menyarankan situs, mempertahankan identitas sumber daya yang stabil saat domain berubah, mengatur item, membuat pratinjau impor markah yang dapat diedit, dan menyelaraskan ikon bilah alat dengan status baca.

3. Penyimpanan lokal dan masa simpan

Data ekstensi disimpan dalam IndexedDB di profil peramban Anda. PathMark tidak memiliki sistem akun atau sinkronisasi cloud. Data tetap berada di perangkat hingga Anda menghapus item, membersihkan pustaka, menghapus ekstensi atau profil peramban, atau mengganti data melalui impor. Cadangan JSON dapat diekspor kapan saja.

4. Pengiriman dan pengungkapan

Ekstensi tidak mengirim URL, judul, catatan, tag, koleksi, status baca, atau konfigurasi situs yang tersimpan kepada pengembang, penyedia analitik, pengiklan, atau pihak ketiga lainnya. Ekstensi tidak memuat iklan, SDK pelacakan, telemetri, atau kode jarak jauh. Situs publik bersifat statis dan tidak menerima data ekstensi.

5. Penjualan dan penggunaan terlarang

PathMark tidak menjual data pengguna dan tidak menggunakannya untuk periklanan, penilaian kredit, pemberian pinjaman, atau tujuan yang tidak terkait dengan satu-satunya fungsi ekstensi. Semua penggunaan informasi yang diperoleh melalui API Chrome mematuhi Kebijakan Data Pengguna Chrome Web Store, termasuk persyaratan penggunaan terbatas.

6. Kendali Anda

  • Edit atau hapus item tersimpan satu per satu.
  • Ekspor seluruh pustaka sebagai JSON.
  • Tolak atau cabut izin markah opsional melalui pengaturan ekstensi peramban sambil tetap menggunakan impor HTML.
  • Bersihkan semua data lokal melalui pengaturan PathMark.
  • Hapus ekstensi untuk menghentikan pemrosesan selanjutnya.

7. Izin

PathMark menggunakan izin tabs untuk membaca URL dan judul tab bila diperlukan agar dapat mengenali halaman tersimpan dan menyelaraskan ikon bilah alat dengan halaman aktif. Informasi ini dinilai secara lokal, tidak digunakan untuk membaca isi halaman, dan tidak dikirim ke mana pun.

PathMark menyatakan bookmarks sebagai izin opsional dan hanya memintanya setelah Anda memilih “Izinkan & baca”. Meskipun peringatan peramban dapat menyebut “membaca dan mengubah markah”, PathMark hanya memanggil API untuk membaca pohon markah; ekstensi tidak membuat, memperbarui, memindahkan, atau menghapus markah asli Anda. Menolak izin tidak memengaruhi impor HTML atau fitur inti lainnya.

8. Perubahan dan kontak

Jika praktik data PathMark berubah secara berarti, kebijakan dan informasi ekstensi ini akan diperbarui sebelum perilaku baru dirilis. Pertanyaan dan permintaan privasi dapat disampaikan melalui pelacak masalah GitHub proyek.
