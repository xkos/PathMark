為真正會回頭閱讀的人設計

從快速收集到重新找到，PathMark 保留的不只是連結，還有你理解這份資料所需的脈絡。

01

跨網域識別同一內容

一個網站可以設定多個網域或 URL 字首。網站遷移後，相同路徑的資料仍能保持穩定身分。

02

閱讀狀態不會混亂

未讀、閱讀中、已讀與歸檔彼此清楚；工具欄圖示會隨目前頁面狀態改變顏色。

03

收藏時留下原因

儲存標題、個人說明、標籤與分類，讓未來的你知道為什麼收藏、接下來重點看什麼。

04

自動匹配已有網站

開啟 Popup 時自動識別目前網域並選擇已有網站，也可以立即建立網站和首個 Endpoint。

05

完整的本機資料庫

按狀態、網站、分類、標籤和日期篩選；支援搜尋、批次整理、身分遷移以及開啟位址切換。

06

資料由你掌控

應用程式資料儲存在瀏覽器本機，可匯出完整 JSON 備份並進行以交易方式合併或還原。

三步建立自己的閱讀記憶

擷取操作保持輕量，真正需要整理時再進入資料庫。

在目前頁面開啟 PathMark

使用工具欄圖示或快捷鍵，立即檢視頁面是否已經儲存及其閱讀狀態。

補充脈絡後收藏

記錄說明、標籤和分類；網站與 Endpoint 會根據目前位址自動建議。

閱讀、遷移、再次找到

即使網域發生變化，也可以透過穩定的網站身分重新識別和開啟同一份資料。

從下一篇「以後再看」開始。
