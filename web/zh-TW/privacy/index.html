隱私政策

PathMark 的設計目標是讓閱讀資料庫始終由你掌控。擴充功能資料僅在瀏覽器本機處理和儲存，不會發送給 PathMark 開發者或任何第三方。

生效日期：2026 年 8 月 15 日 · 適用於 PathMark 瀏覽器擴充功能和官方網站。

0.2.14 · 2026-10-10

網頁收藏連結標記預設關閉。開啟時申請 HTTP/HTTPS 網站存取權限，並使用 scripting 權限檢查連結位址與位置、顯示分類顏色標記。識別僅在本機與收藏資料庫比對，不傳輸連結位址。storage 權限用於在擴充功能本機儲存中保存本裝置的開關選擇，以便重新啟動或更新後恢復腳本註冊。關閉後移除標記並釋放網站存取權限。工具列顏色現表示收藏分類顏色，而非閱讀狀態。

1. PathMark 處理的資料

使用擴充功能時，PathMark 可能處理目前分頁的 URL 和標題、收藏或開啟項目的時間，以及你主動輸入的說明、標籤、分類、閱讀狀態、網站和 Endpoint 規則。當你明確選擇直接匯入瀏覽器收藏夾時，PathMark 還會在本機讀取收藏夾目錄、標題、URL 和收藏時間。PathMark 不讀取頁面本文、密碼、表單內容、Cookie 或完整瀏覽歷史。

2. 資料用途

上述資訊僅用於提供 PathMark 面向使用者的閱讀資料庫功能：識別目前頁面是否已收藏、建議網站、在網站更換網域後維持穩定的資料身分、組織收藏、產生可編輯的收藏夾匯入預覽，以及根據閱讀狀態更新工具欄圖示。

3. 本機儲存與保留期限

擴充功能資料儲存在瀏覽器設定檔內的 IndexedDB 中。PathMark 沒有帳號系統或雲端同步服務。資料會保留在你的裝置上，直到你刪除項目、清空資料庫、移除擴充功能或瀏覽器設定檔，或者透過匯入替換資料。你可以隨時匯出完整 JSON 備份。

4. 傳輸與共享

擴充功能不會把收藏 URL、標題、說明、標籤、分類、閱讀狀態或網站設定傳送給開發者、分析服務、廣告商或其他第三方。擴充功能不包含廣告、追蹤 SDK、遙測或遠端程式碼。公開網站為靜態頁面，不接收擴充功能資料。

5. 出售與禁止用途

PathMark 不出售使用者資料，不將資料用於廣告、信用評估、借貸或與擴充功能單一用途無關的目的。對從 Chrome API 獲得的資訊的使用遵守 Chrome Web Store 使用者資料政策，包括 Limited Use 要求。

6. 你的控制權

  • 編輯或刪除單筆收藏項目。
  • 將完整資料庫匯出為 JSON。
  • 拒絕或透過瀏覽器擴充功能設定撤銷收藏夾可選權限，仍可繼續使用 HTML 匯入。
  • 在 PathMark 設定中清空全部本機應用程式資料。
  • 移除擴充功能以停止未來的資料處理。

7. 權限說明

PathMark 使用 tabs 權限，在識別收藏頁面及讓工具欄圖示與使用中分頁狀態保持同步時讀取分頁 URL 和標題。這些資訊只在本機計算，不用於讀取頁面本文，也不會發送到其他位置。

PathMark 將 bookmarks 宣告為可選權限，只在你點擊「授權並讀取」時請求。瀏覽器的權限提示可能表述為「讀取和變更書籤」，但 PathMark 僅呼叫讀取收藏夾樹的介面，不建立、修改、移動或刪除瀏覽器收藏夾。拒絕該權限不會影響 HTML 匯入或其他核心功能。

8. 政策變更與聯絡

如果 PathMark 的資料處理方式發生實質變化，我們會在釋出新行為之前更新本政策和擴充功能內的揭露。隱私問題和相關請求可以透過專案的 GitHub Issue 提交。
