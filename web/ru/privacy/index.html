Политика конфиденциальности

PathMark разработан так, чтобы ваша библиотека чтения оставалась под вашим контролем. Данные расширения обрабатываются и хранятся локально в браузере и не отправляются разработчику PathMark или третьим лицам.

Дата вступления в силу: 15 августа 2026 года · Применяется к расширению браузера и сайту PathMark.

1. Какие данные обрабатывает PathMark

При использовании расширения PathMark может обрабатывать URL и заголовок текущей вкладки, время сохранения или открытия элемента, а также введённые вами сведения: заметки, теги, коллекции, статус чтения, сайты и правила endpoints. Когда вы явно выбираете прямой импорт из браузера, PathMark также локально читает папки закладок, заголовки, URL и время сохранения. PathMark не читает содержимое страниц, пароли, данные форм, файлы cookie или полную историю браузера.

2. Для чего используются данные

Информация используется только для пользовательских функций библиотеки чтения PathMark: определения, сохранена ли текущая страница, предложения сайта, сохранения стабильной идентичности ресурса при смене доменов, организации элементов, создания редактируемого предпросмотра импорта закладок и обновления значка панели инструментов в соответствии со статусом чтения.

3. Локальное хранение и срок хранения

Данные расширения хранятся в IndexedDB внутри профиля браузера. В PathMark нет системы учётных записей или облачной синхронизации. Данные остаются на устройстве, пока вы не удалите элемент, не очистите библиотеку, не удалите расширение или профиль браузера либо не замените данные импортом. Резервную копию JSON можно экспортировать в любой момент.

4. Передача и раскрытие данных

Расширение не передаёт сохранённые URL, заголовки, заметки, теги, коллекции, статусы чтения или настройки сайтов разработчику, поставщикам аналитики, рекламодателям или другим третьим лицам. Оно не содержит рекламы, SDK отслеживания, телеметрии или удалённого кода. Общедоступный сайт является статическим и не принимает данные расширения.

5. Продажа и запрещённое использование

PathMark не продаёт пользовательские данные и не использует их для рекламы, оценки кредитоспособности, кредитования или целей, не связанных с единственным назначением расширения. Любое использование информации, полученной через API Chrome, соответствует Политике пользовательских данных Chrome Web Store, включая требования ограниченного использования.

6. Ваши средства управления

  • Изменять или удалять отдельные сохранённые элементы.
  • Экспортировать всю библиотеку в формате JSON.
  • Отклонить или отозвать необязательное разрешение на закладки в настройках расширений браузера, продолжая использовать импорт HTML.
  • Очистить все локальные данные в настройках PathMark.
  • Удалить расширение, чтобы прекратить дальнейшую обработку.

7. Разрешения

PathMark использует разрешение tabs, чтобы при необходимости читать URL и заголовок вкладки для распознавания сохранённых страниц и синхронизации значка панели инструментов с активной страницей. Эта информация оценивается локально, не используется для чтения содержимого страницы и никуда не отправляется.

PathMark объявляет bookmarks необязательным разрешением и запрашивает его только после нажатия «Разрешить и прочитать». Хотя предупреждение браузера может говорить «читать и изменять закладки», PathMark вызывает только API чтения дерева закладок; расширение не создаёт, не обновляет, не перемещает и не удаляет исходные закладки. Отказ от разрешения не влияет на импорт HTML и другие основные функции.

8. Изменения и связь

Если правила работы PathMark с данными существенно изменятся, эта политика и сведения расширения будут обновлены до выпуска нового поведения. Вопросы и запросы о конфиденциальности можно отправить через систему задач GitHub проекта.
