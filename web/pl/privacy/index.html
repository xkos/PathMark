Polityka prywatności

PathMark został zaprojektowany tak, aby kontrola nad biblioteką lektur pozostawała w Twoich rękach. Dane rozszerzenia są przetwarzane i przechowywane lokalnie w przeglądarce i nie są wysyłane do programisty PathMark ani stron trzecich.

Data wejścia w życie: 15 sierpnia 2026 r. · Dotyczy rozszerzenia przeglądarki i witryny PathMark.

1. Dane przetwarzane przez PathMark

Podczas korzystania z rozszerzenia PathMark może przetwarzać URL i tytuł bieżącej karty, czas zapisania lub otwarcia elementu oraz wprowadzone informacje, takie jak notatki, tagi, kolekcje, stan czytania, witryny i reguły endpointów. Gdy wyraźnie wybierzesz bezpośredni import z przeglądarki, PathMark lokalnie odczyta również foldery zakładek, tytuły, URL-e i czas zapisania. PathMark nie odczytuje treści stron, haseł, danych formularzy, plików cookie ani całej historii przeglądania.

2. Cel wykorzystania danych

Informacje są używane wyłącznie do funkcji biblioteki lektur PathMark: ustalania, czy bieżąca strona jest zapisana, sugerowania witryny, zachowywania stabilnej tożsamości zasobu przy zmianie domen, organizowania elementów, tworzenia edytowalnego podglądu importu zakładek i synchronizowania ikony paska narzędzi ze stanem czytania.

3. Lokalne przechowywanie i okres przechowywania

Dane rozszerzenia są przechowywane w IndexedDB w profilu przeglądarki. PathMark nie ma systemu kont ani synchronizacji w chmurze. Dane pozostają na urządzeniu, dopóki nie usuniesz elementu, nie wyczyścisz biblioteki, nie usuniesz rozszerzenia lub profilu przeglądarki albo nie zastąpisz danych przez import. Kopię JSON można wyeksportować w dowolnym momencie.

4. Przesyłanie i ujawnianie danych

Rozszerzenie nie wysyła zapisanych URL-i, tytułów, notatek, tagów, kolekcji, stanów czytania ani konfiguracji witryn do programisty, dostawców analiz, reklamodawców ani innych stron trzecich. Nie zawiera reklam, zestawów SDK do śledzenia, telemetrii ani zdalnego kodu. Publiczna witryna jest statyczna i nie przyjmuje danych rozszerzenia.

5. Sprzedaż i zabronione wykorzystanie

PathMark nie sprzedaje danych użytkowników i nie wykorzystuje ich do reklamy, oceny zdolności kredytowej, udzielania kredytów ani celów niezwiązanych z jedynym przeznaczeniem rozszerzenia. Każde użycie informacji uzyskanych przez interfejsy API Chrome jest zgodne z Zasadami dotyczącymi danych użytkowników Chrome Web Store, w tym z wymogami ograniczonego użycia.

6. Dostępne opcje kontroli

  • Edytuj lub usuwaj pojedyncze zapisane elementy.
  • Eksportuj całą bibliotekę jako JSON.
  • Odrzuć lub cofnij opcjonalne uprawnienie do zakładek w ustawieniach rozszerzeń przeglądarki, nadal korzystając z importu HTML.
  • Wyczyść wszystkie dane lokalne w ustawieniach PathMark.
  • Odinstaluj rozszerzenie, aby zatrzymać dalsze przetwarzanie.

7. Uprawnienia

PathMark korzysta z uprawnienia tabs, aby w razie potrzeby odczytać URL i tytuł karty w celu rozpoznania zapisanych stron i zsynchronizowania ikony paska narzędzi z aktywną stroną. Informacje są oceniane lokalnie, nie służą do odczytywania treści strony i nie są nigdzie wysyłane.

PathMark deklaruje bookmarks jako uprawnienie opcjonalne i prosi o nie dopiero po wybraniu „Zezwól i odczytaj”. Choć ostrzeżenie przeglądarki może mówić o „odczytywaniu i zmienianiu zakładek”, PathMark wywołuje tylko interfejs API odczytu drzewa zakładek; nie tworzy, aktualizuje, przenosi ani nie usuwa oryginalnych zakładek. Odmowa nie wpływa na import HTML ani inne podstawowe funkcje.

8. Zmiany i kontakt

Jeśli praktyki PathMark dotyczące danych ulegną istotnej zmianie, ta polityka i informacje o rozszerzeniu zostaną zaktualizowane przed wydaniem nowego zachowania. Pytania i prośby dotyczące prywatności można przesyłać przez system zgłoszeń GitHub projektu.
