سياسة الخصوصية

صُمم PathMark كي تبقى مكتبة القراءة تحت سيطرتك. تُعالج بيانات الإضافة وتُخزن محليًا في متصفحك ولا تُرسل إلى مطور PathMark أو إلى أطراف ثالثة.

تاريخ السريان: 15 أغسطس 2026 · تنطبق على إضافة PathMark للمتصفح وموقعه.

0.2.14 · 2026-10-10

تمييز الروابط المحفوظة اختياري ومعطل افتراضيًا. يطلب تفعيله الوصول إلى مواقع HTTP/HTTPS. يقرأ إذن scripting عناوين الروابط ومواضعها لعرض علامات بألوان المجموعات، وتتم المطابقة محليًا دون إرسال العناوين. يحفظ إذن storage الاختيار محليًا لاستعادته بعد إعادة التشغيل أو التحديث. يؤدي الإيقاف إلى إزالة العلامات وإذن الوصول. يعبر لون الأيقونة الآن عن المجموعة بدلًا من حالة القراءة.

1. البيانات التي يعالجها PathMark

عند استخدام الإضافة، قد يعالج PathMark عنوان URL وعنوان علامة التبويب الحالية، ووقت حفظ العنصر أو فتحه، والمعلومات التي تدخلها مثل الملاحظات والوسوم والمجموعات وحالة القراءة والمواقع وقواعد نقاط النهاية. وعندما تختار صراحة الاستيراد المباشر من المتصفح، يقرأ PathMark محليًا مجلدات الإشارات وعناوينها وعناوين URL وأوقات الحفظ. لا يقرأ PathMark محتوى الصفحات أو كلمات المرور أو بيانات النماذج أو ملفات تعريف الارتباط أو سجل التصفح كاملًا.

2. الغرض من استخدام البيانات

تُستخدم المعلومات فقط لميزات مكتبة القراءة الموجهة للمستخدم: تحديد ما إذا كانت الصفحة الحالية محفوظة، واقتراح موقع، والحفاظ على هوية مورد مستقرة عند تغير النطاقات، وتنظيم العناصر، وإنشاء معاينة قابلة للتحرير لاستيراد الإشارات، ومزامنة رمز شريط الأدوات مع حالة القراءة.

3. التخزين المحلي ومدة الاحتفاظ

تُخزن بيانات الإضافة في IndexedDB داخل ملف تعريف المتصفح. لا يحتوي PathMark على نظام حسابات أو مزامنة سحابية. تبقى البيانات على الجهاز حتى تحذف عنصرًا أو تمسح المكتبة أو تزيل الإضافة أو ملف المتصفح أو تستبدل البيانات عبر الاستيراد. ويمكنك تصدير نسخة JSON احتياطية في أي وقت.

4. نقل البيانات والإفصاح عنها

لا ترسل الإضافة عناوين URL أو العناوين أو الملاحظات أو الوسوم أو المجموعات أو حالات القراءة أو إعدادات المواقع المحفوظة إلى المطور أو مزودي التحليلات أو المعلنين أو أي طرف ثالث. ولا تتضمن إعلانات أو حزم تتبع أو قياسًا عن بعد أو شفرة بعيدة. الموقع العام ثابت ولا يستقبل بيانات الإضافة.

5. البيع والاستخدامات المحظورة

لا يبيع PathMark بيانات المستخدم ولا يستخدمها للإعلانات أو تقييم الجدارة الائتمانية أو الإقراض أو أي غرض لا يتعلق بالغرض الوحيد للإضافة. ويتوافق كل استخدام للمعلومات المستمدة من واجهات Chrome مع سياسة بيانات مستخدمي Chrome Web Store، بما فيها متطلبات الاستخدام المحدود.

6. عناصر التحكم المتاحة لك

  • تعديل العناصر المحفوظة أو حذفها فرديًا.
  • تصدير المكتبة كاملة بصيغة JSON.
  • رفض إذن الإشارات الاختياري أو سحبه من إعدادات إضافات المتصفح مع مواصلة استخدام استيراد HTML.
  • مسح كل البيانات المحلية من إعدادات PathMark.
  • إلغاء تثبيت الإضافة لإيقاف المعالجة المستقبلية.

7. الأذونات

يستخدم PathMark إذن tabs لقراءة عنوان URL وعنوان علامة التبويب عند الحاجة للتعرّف على الصفحات المحفوظة ومزامنة رمز شريط الأدوات مع الصفحة النشطة. تُقيّم المعلومات محليًا، ولا تُستخدم لقراءة محتوى الصفحة، ولا تُرسل إلى أي مكان.

يعلن PathMark عن bookmarks كإذن اختياري ولا يطلبه إلا بعد اختيار «السماح والقراءة». ورغم أن تحذير المتصفح قد يذكر «قراءة الإشارات المرجعية وتغييرها»، فإن PathMark يستدعي فقط واجهة قراءة شجرة الإشارات؛ ولا ينشئ الإشارات الأصلية أو يحدثها أو ينقلها أو يحذفها. لا يؤثر الرفض في استيراد HTML أو الميزات الأساسية الأخرى.

8. التغييرات والتواصل

إذا تغيرت ممارسات بيانات PathMark تغيرًا جوهريًا، فستُحدّث هذه السياسة ومعلومات الإضافة قبل إصدار السلوك الجديد. يمكنك إرسال أسئلة وطلبات الخصوصية عبر متعقب مشكلات GitHub الخاص بالمشروع.
