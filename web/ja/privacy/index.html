プライバシーポリシー

PathMark は、読書ライブラリを利用者自身が管理できるよう設計されています。拡張機能のデータはブラウザ内で処理・保存され、PathMark の開発者や第三者には送信されません。

施行日: 2026 年 8 月 15 日 · PathMark ブラウザ拡張機能およびウェブサイトに適用されます。

1. PathMark が取り扱うデータ

拡張機能の使用時、PathMark は現在のタブの URL とタイトル、項目を保存または開いた日時、利用者が入力したメモ、タグ、コレクション、読書ステータス、サイト、Endpoint ルールを取り扱う場合があります。ブラウザから直接インポートする操作を明示的に選んだ場合は、ブックマークのフォルダー、タイトル、URL、保存日時もローカルで読み取ります。ページ本文、パスワード、フォーム入力、Cookie、ブラウザ履歴全体は読み取りません。

2. データの利用目的

これらの情報は、現在のページが保存済みかの識別、サイトの提案、ドメイン変更時にも安定したリソース識別情報を保つこと、項目の整理、編集可能なブックマークインポートのプレビュー作成、読書ステータスを反映したツールバーアイコンの更新など、PathMark の読書ライブラリ機能を提供するためだけに使用されます。

3. ローカル保存と保持期間

拡張機能のデータはブラウザプロファイル内の IndexedDB に保存されます。PathMark にアカウント機能やクラウド同期サービスはありません。項目の削除、ライブラリの消去、拡張機能またはブラウザプロファイルの削除、インポートによる置換を行うまで、データは端末内に残ります。JSON バックアップはいつでも書き出せます。

4. 送信と共有

拡張機能は、保存した URL、タイトル、メモ、タグ、コレクション、読書ステータス、サイト設定を、開発者、分析事業者、広告事業者、その他の第三者へ送信しません。広告、追跡 SDK、テレメトリー、リモートコードは含まれません。公開ウェブサイトは静的で、拡張機能のデータを受け取りません。

5. 販売および禁止される利用

PathMark は利用者データを販売せず、広告、信用力評価、融資、または拡張機能の単一目的と無関係な用途には使用しません。Chrome API から取得した情報の利用は、限定的使用の要件を含む Chrome ウェブストアのユーザーデータポリシーに従います。

6. 利用者が行える管理

  • 保存した項目を個別に編集または削除する。
  • ライブラリ全体を JSON として書き出す。
  • HTML インポートを引き続き利用しながら、ブラウザの拡張機能設定で任意のブックマーク権限を拒否または取り消す。
  • PathMark の設定からすべてのローカルデータを消去する。
  • 拡張機能を削除して今後の処理を停止する。

7. 権限

PathMark は tabs 権限を使用し、保存済みページの識別とアクティブページに合わせたツールバーアイコンの更新に必要な場合に、タブの URL とタイトルを読み取ります。この情報はローカルで評価され、ページ本文の読み取りや外部への送信には使用されません。

PathMark は bookmarks を任意の権限として宣言し、利用者が「承認して読み込む」をクリックした後にだけ要求します。ブラウザの警告に「ブックマークの読み取りと変更」と表示される場合がありますが、PathMark が呼び出すのはブックマークツリーを読み取る API だけです。元のブックマークを作成、更新、移動、削除することはありません。この権限を拒否しても、HTML インポートやその他の主要機能には影響しません。

8. 変更とお問い合わせ

PathMark のデータ取扱いを実質的に変更する場合、新しい動作を公開する前に本ポリシーと拡張機能の開示内容を更新します。質問やプライバシーに関する依頼は、プロジェクトの GitHub Issue から送信できます。
