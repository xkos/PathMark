本当に「後で読む」人のために

手早い保存から再発見まで、PathMark はリンクだけでなく、未来の自分に必要な背景も残します。

01

ドメインをまたいで同じ内容を識別

1 つのサイトに複数のドメインや URL プレフィックスを登録できます。サイトが移転しても、対応するパスに安定したコンテンツ識別情報を保てます。

02

分かりやすい読書ステータス

未読、読書中、読了、アーカイブを明確に区別します。ツールバーアイコンの色で現在ページの状態も確認できます。

03

URL だけでなく、保存した理由も

タイトル、個人メモ、タグ、コレクションを記録し、なぜ重要だったのか、後で何を見るべきかを思い出せます。

04

既存サイトを自動照合

Popup が現在のドメインを認識し、登録済みサイトを選択します。未登録なら新しいサイトと最初の Endpoint の作成を支援します。

05

充実したローカルライブラリ

状態、サイト、コレクション、タグ、日付で検索・絞り込み。一括整理、識別情報の移行、開くアドレスの選択にも対応します。

06

データの所有者はあなた

ライブラリのデータはブラウザ内に保存されます。完全な JSON バックアップを書き出し、トランザクション単位でマージまたは復元できます。

3 ステップで読書の記憶をつくる

保存は軽快に。詳しい整理は必要になったときだけ行えます。

任意のページで PathMark を開く

ツールバーアイコンまたはショートカットから、そのページが保存済みか、どの読書状態かをすぐ確認できます。

背景を加えて保存

メモ、タグ、コレクションを記録します。現在の URL からサイトと Endpoint が自動提案されます。

読み、移行し、再発見する

ドメインが変わった後も、安定したサイト識別情報によって同じリソースを再び認識して開けます。

次に「後で読む」と思ったページから始めましょう。

Chrome ウェブストアから PathMark を追加し、読む予定、読書中、読了済みの資料を整理しましょう。開発者向けには GitHub でソースと単体ビルドも公開しています。
